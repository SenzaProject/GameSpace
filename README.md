# Game Space

Pusat kontrol gaming untuk Android (root) oleh **SenzaProject**.

- Pembaca FPS real-time via root (SurfaceFlinger) + overlay FPS melayang
- Deteksi game otomatis, statistik sesi (avg/min/max/1% low), grafik live
- Boost RAM, Mode Performa, Jangan Ganggu
- minSdk 26 (Android 8.0), target 34

## Build
Push ke GitHub, lalu tab **Actions -> Build APK**. APK ada di *Artifacts* (GameSpace-APK).

Lokal: `gradle assembleDebug` (Gradle 8.9, JDK 17, Android SDK 34).
